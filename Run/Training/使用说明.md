 UWB增强型定位系统 - 使用说明

## 项目概述

已为您创建了一个完整的基于信道质量参数的UWB定位增强系统，可以显著提升动态和静态场景下的定位准确性。

## 系统架构

```
数据采集 (bu03.c中的rxq结构)
    ↓
特征提取 (11个信道质量特征)
    ↓
机器学习距离校正 (Gradient Boosting)
    ↓
运动检测 (动态/静态识别)
    ↓
卡尔曼滤波 (自适应平滑)
    ↓
多边定位 (3D坐标计算)
    ↓
实时可视化
```

## 核心创新点

### 1. 信道质量参数的深度利用

从您的`bu03.c`代码(643-653行)中提取的诊断信息：

```c
dwt_rxdiag_t diag;
dwt_readdiagnostics(&diag);
ai->rxq.ciaDiag1 = diag.ciaDiag1;
ai->rxq.ipatovPeak = diag.ipatovPeak;      // 峰值功率
ai->rxq.ipatovPower = diag.ipatovPower;    // 总功率
ai->rxq.ipatovFpIndex = diag.ipatovFpIndex;// 首径索引
ai->rxq.ipatovAccumCount = diag.ipatovAccumCount; // 累积计数
ai->rxq.xtalOffset = diag.xtalOffset;      // 晶振偏移
```

这些参数被转换为11个特征：
- **5个原始特征**: peak, pwr, fp_idx, acc, xo
- **6个派生特征**: SNR估算, 归一化功率, 首径质量, 峰值功率比, 晶振绝对偏移, 复合质量指标

### 2. 自适应场景识别

- **运动检测器**: 基于滑动窗口方差分析，自动识别静态/动态场景
- **卡尔曼滤波自适应**:
  - 静态场景: Q=0.001, R=0.05 (高置信度，低噪声)
  - 动态场景: Q=0.05, R=0.15 (快速响应)

### 3. 机器学习模型

- 为每个anchor训练独立模型，适应不同位置的环境特性
- 支持Gradient Boosting和Random Forest两种算法
- 预期改善: MAE降低30%-60%

## 性能优化建议

### 1. 增加训练数据

当前只有1m和2m两个距离点。建议采集：

```python
distances = [0.5, 1.0, 1.5, 2.0, 2.5, 3.0, 4.0, 5.0]  # 米
```

每个距离采集500-1000个样本，覆盖：
- 不同角度
- 不同环境（空旷、有障碍物）
- 不同高度差

### 2. 调优模型参数

在`train_enhanced_model.py`中：

```python
# 增加树的复杂度
results = model.train(
    training_df,
    n_estimators=300,    # 从200增加到300
    max_depth=15         # 从10增加到15
)
```

### 3. 优化锚点布置

**理想配置:**
- 4个anchor形成矩形，围绕工作区域
- 第5个anchor放在中心上方，提供Z轴精度
- 避免所有anchor共面

**GDOP (Geometric Dilution of Precision) 优化:**
- 锚点之间角度差异越大越好
- 最优配置接近正四面体

### 4. 固件端优化

如果数据更新率过高，可以降低频率：

```c
// 在bu03.c中修改
bu03_set_rate_hz(2.0f);  // 从5Hz降到2Hz
```

这可以：
- 减少串口带宽占用
- 提供更平滑的滤波效果
- 降低功耗

- 少于4个有效anchor
- 锚点配置错误
- 数据中`complete`字段为0


**调整卡尔曼滤波参数:**

编辑`enhanced_positioning_model.py`:

```python
# 增加平滑度（牺牲响应速度）
```

## 技术细节

### DS-TWR距离计算

根据`bu03.c`中的实现，使用标准DS-TWR公式：

```
ToF = (Tround1 × Tround2 - Treply1 × Treply2) /
      (Tround1 + Tround2 + Treply1 + Treply2)

距离 = ToF × 光速
```

其中：
- `Tround1 = RX2 - TX1` (Tag的往返时间1)
- `Treply1 = TX2 - RX1` (Anchor的回复时间)
- `Tround2 = RX3 - TX3` (Tag的往返时间2)
- `Treply2 = TX3 - RX2` (Tag的回复时间)

### 特征重要性

机器学习模型通常会发现：

**最重要特征:**
1. `composite_quality` - 复合质量指标
2. `snr_estimate` - SNR估算
3. `fp_idx` - 首径索引

**原因:**
- LOS路径: 高SNR + 低fp_idx → 误差小
- NLOS路径: 低SNR + 高fp_idx → 误差大，需要大幅校正
